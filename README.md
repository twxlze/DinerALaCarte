# DinerALaCarte

DinerALaCarte facilite l'organisation des événements culinaires en aidant les hôtes à gérer leurs invitations et menus. L'application permet d'enregistrer les invités, de définir les plats et de prendre en compte les restrictions alimentaires (allergies) ou les goûts personnels (plats préférés/detestés) pour garantir une expérience sans faute aux invités. ^^
